FEATURES

调试 Webhook 该有的，这里都有

从接收、检查到清理，覆盖回调联调的完整链路，而不是只给你一个 RequestBin。

任意请求，照单全收

GET / POST / PUT / PATCH / DELETE 全支持，多级子路径与查询参数原样保留，不挑调用方。

完整请求快照

请求头、查询串、Content-Type、来源 IP、UA、原始请求体，一条不落地存下来。

JSON 与二进制都能看

JSON 自动格式化并保留解析副本，文本 UTF-8 存储，二进制 Base64 无损保存。

安全默认开启

Token 仅存 SHA-256 哈希，Authorization / Cookie 等敏感头入库前脱敏，管理接口独立鉴权。

检索、分页与统计

按端点、方法、时间筛选，分页浏览历史，一眼看清请求量趋势与活跃端点。

自动过期清理

定时任务按保留天数清理历史，支持每个端点单独覆盖，设为 0 即永久保留。

interface Endpoint {
  id: string
  name: string
  enabled: boolean
  request_count: number
}

async function listEndpoints(token: string): Promise<Endpoint[]> {
  const res = await fetch('/api/v1/endpoints', {
    headers: { Authorization: 'Bearer ' + token },
  })
  const body = await res.json()
  return body.data.items as Endpoint[]
}

            FAQ
            
常见问题

          

          

            
这个在线演示的数据会保存多久？
首页 Live Demo 使用公开的临时端点，30 分钟后自动失效，数据仅保存在内存中、冷启动即清空，且任何拿到地址的人都能查看。请勿发送真实或敏感数据。正式使用请自托管。

            
与 RequestBin / Webhook.site 有什么不同？
核心能力相近，但本项目完全开源可自托管，数据留在你自己的 Cloudflare D1 或服务器里；同时提供端点管理、Token 轮换、保留策略与 OpenAPI 文档，方便接进内部工具链。

            
生产环境需要付费吗？
不需要。主方案运行在 Cloudflare Workers + D1 免费额度内，不需要 Workers Paid 功能。本演示站点可部署在 Vercel 免费计划。

            
Token 和敏感信息怎么处理？
端点 Token 是 256-bit 随机值，数据库只保存 SHA-256 哈希，明文仅在创建或轮换时返回一次。Authorization、Cookie 等敏感请求头在入库前就会被替换为 [redacted]。

            
支持多大的请求体？可以永久保留吗？
默认上限 512 KB，可通过 MAX_BODY_SIZE 调整，超限返回 413。默认按 RETENTION_DAYS 定时清理；把单个端点的 retention_days 设为 0 即可跳过自动清理。
